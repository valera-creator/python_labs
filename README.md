реализовывать алгоритмы, выполняющие стандартные операции с множествами.<br><br>
1. Пользователь вводит 10 слов, разделённых точкой с запятой, а
затем контрольную строку на отдельной строке. Выведите
только те слова, которые начинаются с контрольной строки.<br><br>
2. Существует математическая гипотеза, которая строится на
предположении, что любое натуральное число N может быть
превращено в 1 в результате последовательного выполнения
следующих действий:<br>
• если оно чётное, то делим его на 2<br>
• если нечётное, то умножаем на 3 и прибавляем 1<br>
Над полученным числом вышеописанные действия
выполняются вновь до тех пор, пока не получится 1.<br>
Пример: 16 -> 8 -> 4 -> 2 -> 1<br>
13 -> 40 -> 20 -> 10 -> 5 -> 16 -> 8 -> 4 -> 2 -> 1<br>
Пиком последовательности называют наибольшее из чисел,
полученных в процессе преобразования числа N в 1. В примере
пик последовательности отмечен красным.
Напишите программу, которая принимала бы на вход число N,
а затем выводила бы на консоль саму последовательность,
количество элементов в последовательности и её пик.<br><br>
3. На вход программе подаётся путь к файлу с расширением txt,
где на каждой новой строке содержатся информация с
именами участников конкурса и их баллами. Значения в строке
могут быть разделены любым количеством пробелов.<br>
Пример файла:<br>
Василий 70<br>
Светлана 90<br>
Алиса 60<br>
Считайте информацию из файла, а затем выполните
следующие задачи:<br>
• Отсортируйте участников конкурса по имени, результат
выведите на консоль.<br>
• Отсортируйте участников конкурса по количеству
набранных баллов, результат выведите на консоль.<br>
• Выведите в файл res.txt имена только тех участников, чей
результат превышает значение N, введённое
пользователем.<br>
Для решения всех задач из этого номера необходимо
использовать функции высшего порядка.<br><br>
4. На вход программе подаётся путь к файлу с расширением txt, в
котором содержится текст. Напишите программу, которая
подсчитывала бы частоту встречаемости символов в тексте без
учёта регистра, а затем выводила бы результат в файл res.txt в
формате «символ: частота встречаемости».<br>
Пример:<br>
Входной файл: res.txt<br>
Мама <br>м: 2<br>
а: 2<br>
